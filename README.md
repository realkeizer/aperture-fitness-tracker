DISCLAIMER: This project was NOT vibe coded. All written code is my own and stems from my own learning/understanding. While LLMs have been used tertiarily for learning purposes, they have had exactly zero input on the code written in any of these directories. I'm in this for the love of the game.

This program is a passion project of mine born purely of spite. I've tried many workout trackers/planners etc, but they're always full of features I don't need and either lacking features I do or locking them behind paywalls. Personally, I'm a bit of a control freak - I like knowing exactly what inputs lead to what outputs - hence, this program. 

Aperture, when finished, will be a full fitness tracker complete with workout logging, macro logging, data analysis, and graphing capabilities. It will include basic averages, predictions, correlation graphs and more. 

Why? Because I'm a nerd. Is this at all necessary for health, wellness, and longevity? Absolutely f***ing not. But, is it useful..? In some cases - if you're the type of person who wants to use accurate historical data trends for optimisation. This can be used to calculate your exact, actual TDEE rather than having to rely on online calculators that operate based on generalised formulas. Want to know your exact lean bulk calories? Or the exact conditions under which you hit your strongest deadlift, so you can replicate them for another PR attempt? Now, you can (or rather, you will... when I actually finish). That's the real strength of this program - and it's why I'm building it.

If you're wondering about the inspiration for the name, it's actually from the Portal 2 series - I want to build a GLaDOS-inspired robot that speaks and receives voice commands. Firstly, because it sounds fun. Secondly, because I can then hand off the boring data logging to something that won't complain about it.

(Fun fact: When I started learning Python, a version of this project was the first thing I ever coded. It used a single .csv file for data storage and ran calculations and plotted graphs from it, and it was an absolute nightmare.)
